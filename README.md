# NLW Pocket ✨

Este é um projeto de aplicação web para gerenciamento de prompts, desenvolvido durante o evento NLW. O objetivo é permitir que o usuário crie, salve, pesquise, copie e remova prompts de forma simples e rápida, com uma interface responsiva e moderna.

## Funcionalidades

- Criação de novos prompts;
- Edição e remoção de prompts existentes;
- Busca de prompts por título;
- Cópia rápida do conteúdo do prompt;
- Interface responsiva para desktop e mobile;
- Sidebar colapsável;
- Dados salvos no navegador (localStorage).

## Tecnologias Utilizadas

- HTML5
- CSS3 (com responsividade)
- JavaScript (Vanilla)

## Como usar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Utilize a interface para criar, buscar, copiar e remover prompts.

## Estrutura de Pastas

```
NLW Pocket/
├── index.html
├── style.css
├── script.js
└── assets/
```

## Observações

- Não é necessário backend ou instalação de dependências.
- Todos os dados ficam salvos localmente no navegador.
